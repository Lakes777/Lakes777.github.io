sobre

Sobre mim

Sou de Curitiba, PR e curso Engenharia de Software na PUC-PR. Meu foco é back-end: APIs REST com Java (Spring Boot), Python (FastAPI), Go e C# (.NET), bancos PostgreSQL com SQL escrito à mão e testes automatizados em tudo: são mais de 3.000, rodando no GitHub Actions.

Gosto de ver os projetos funcionando de verdade: eles estão no ar na Vercel, no Render e em VMs Linux da Oracle com Docker e HTTPS. Quando o projeto pede uma interface, faço o front-end com React e TypeScript.

Fora do código, curto hardware: manutenção de computadores e protótipos de IoT com ESP32 e Arduino.

Estou em busca de oportunidades em desenvolvimento, suporte técnico ou análise de dados, onde eu possa aplicar o que sei e continuar aprendendo.
