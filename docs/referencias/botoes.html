Botões do início: 3 opções

Passe o mouse em cada um (e teste o Tab do teclado). Dá para misturar: o principal de uma com os secundários de outra.

A · Varredura

Uma luz atravessa o botão principal e a seta anda; nos outros, um azul entra pela esquerda, a borda acende e o botão sobe um pouco.

B · Traço

O mesmo movimento das abas: um traço antes do texto cresce e fica azul. Os secundários não têm borda, só acendem no hover. É o mais sóbrio e o mais coerente com o menu.

ver projetos github linkedin

C · Marcas de canto

Cantos de visor de engenharia que se abrem no hover; no principal, um cursor de terminal pisca depois do texto. É o que mais chama atenção e o mais "técnico".
